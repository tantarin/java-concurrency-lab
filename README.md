# Java Threads

Короткий русскоязычный учебник по многопоточности в Java. Это PWA: сайт можно установить на главный экран iPhone и читать офлайн.

Курс связан с рабочим проектом [`downloader`](./downloader): главы ведут на конкретные строки Java-кода, чтобы каждый механизм многопоточности можно было увидеть в прикладном сценарии.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Java-проект

```bash
cd downloader
mvn test
```

Инструкция по запуску менеджера загрузок находится в [`downloader/README.md`](./downloader/README.md).
